# Dataset

## Fonte

O dataset é disponibilizado no Kaggle com o nome: **Stroke Prediction Dataset**.

## Características

- 5.110 registros
- 11 atributos preditivos
- Variável alvo: `stroke`

## Colunas Principais

| Coluna | Descrição |
|---|---|
| `id` | Identificador do paciente |
| `gender` | Gênero |
| `age` | Idade |
| `hypertension` | Hipertensão |
| `heart_disease` | Doença cardíaca |
| `ever_married` | Estado civil |
| `work_type` | Tipo de trabalho |
| `Residence_type` | Tipo de residência |
| `avg_glucose_level` | Glicose média |
| `bmi` | Índice de massa corporal |
| `smoking_status` | Status de tabagismo |
| `stroke` | Variável alvo |

## Observações

O file conta com casos positivos bastante raros, representando aproximadamente 4,87% do dataset. Esse desbalanceamento deve ser considerado em análises de avaliação e modelagem.
